# 決定と、その理由

tadori で決めたことと、なぜそう決めたかを残します。覆すときは理由を書いて新しい項を足します（古い項は消しません）。

## 2026-11-05 手元で開く画面を持つ

**`tadori serve` で、手元（127.0.0.1）に画面を開く。**

- 「リリースまで進めてよいか」は、工程をまたいだ関門・遅れ・記録を 1 か所で見ないと判断しにくい。CLI の一覧だけでは足りなかった
- ただし画面は判定を持たない。判定は CLI・CI と同じ核（`@tadori/core`）を通す。画面だけの判定を作ると、CI と結果が食い違う
- 割合（○%）や点数は出さない。出すのは漏れの中身と件数、人の承認待ち、作業のステータス、遅れた日数という事実だけ。
  割合を出すと、それを上げるための形だけの行が増える

## 2026-11-05 正本は増やさない。tadori が書くのは設定と記録だけ

- 設計書・検証シート・WBS の正本は、それぞれの道具（md-business の文書・TSV）にある。tadori は読んでつなぐ
- WBS の作業は台帳に書き写さず、読み込むときに台帳の行（種類 `W`）として扱う。書き写すと正本が 2 つになる
- tadori が書くのは、工程・ステータス・ルールセットの設定（`.tadori/`）と、チェックの記録（`.tadori/checks.tsv`・5W1H）。
  画面で WBS のステータスを変えたときは、`ledger/wbs.tsv` のそのセルだけを書き換える（ほかの行や `#` の行は触らない）

## 2026-11-05 保存は git の commit で残す。push は人

- 画面やエージェントが保存したら、案件のリポジトリに commit する。各担当が自分のクローンで作業して push すれば、全員の操作が履歴に残る
- push は人が中身を確かめてから行う。tadori は push しない
- 案件のフォルダがそれ自身の git リポジトリでないときは commit しない（ほかのリポジトリに記録が混ざるのを防ぐ）

## 2026-11-05 外の道具とは同期しない

- GitHub・GitLab・課題管理などは、エージェントがその都度読む
- 外の記録は後から書き換えられることがあり、止まれば読めなくなる。大事なのは「tadori がその時点でどう見たか」なので、
  読んだ時点の記録（時刻・取得元・要約・中身のハッシュ）を tadori の側に残す
- 認証は各道具の CLI や環境変数に任せ、トークンは設定にも台帳にも書かない

## 2026-11-05 用語は「漏れ」

ルールが求めるつながりが無い箇所を「漏れ」と呼ぶ（以前の文書の「穴」）。人が最後に認める言葉も「確かにそこが漏れていた」にそろえる。

## 2026-11-05 ルールの判定は 4 種類

| 種類 | 意味 | 例 |
|---|---|---|
| `covered` | その種類のどの行にも、それを元にした下流の行がある | 観点ごとに試験ケースがある |
| `refers` | その種類のどの行も、上流の行を元にしている | どの基本設計の章にも WBS の作業が紐づいている |
| `filled` | その種類のどの行にも、決めた列の値が入っている | 詳細設計の節に「改修後の対応」が書いてある |
| `approval` | 人の承認が要る。tadori は承認の記録を見るだけで、代わりに承認しない | 基本設計書をレビュー担当が承認した |

`only` 列（`列名=値`）で対象の行を絞れる（例：改修後に「変わる」節だけ commit を求める）。
つながりは台帳に書かれた ID だけで決める。推測でつながない。

## 2026-11-05 技術の選び方（MVP）

| 何に | 何を | なぜ |
|---|---|---|
| パッケージ管理 | pnpm（workspace） | install script の許可制と、公開直後の版を入れない設定が標準で使える |
| 判定の核・CLI | TypeScript・Node 22 以上。実行時の依存は持たない | 判定は CI でも pre-commit でも動く必要がある。依存が少ないほど壊れにくい |
| テスト | Vitest | TypeScript をそのまま走らせられ、速い |
| 画面 | ビルドの要らない素の JavaScript（ES modules）を `tadori serve` がそのまま配る | 叩きから早く移すため。**型が無いのは借り**で、次の段で TypeScript に移す |
| サーバー | Node の `http` だけ。127.0.0.1 にだけつなぐ | 同じ網のほかの PC から見えないようにする。書き込みには独自ヘッダを求め、ほかのサイトからの書き込みを防ぐ |

デスクトップアプリとして包む（Tauri など）・MCP の口・資料の版と差分の画面は、次の段で決める。
