Before you install

Node.js 22 or later is required. tadori's checks and server run on Node.js. If you don't have it, install the LTS version from the official Node.js website.

Not sure which CPU you have?

  • macOS: Apple menu › About This Mac. If Chip says Apple M…, it's Apple silicon; if Processor says Intel…, it's Intel.
  • Windows: Settings › System › About. If System type says “x64-based”, it's x64; if it says “ARM-based”, it's ARM.

Opening it for the first time

The current installers are not code-signed. The first time you open tadori, your OS or antivirus software may ask you to confirm.

  • macOS: if you see “cannot verify the developer”, right-click tadori in Finder and choose Open.
  • Windows: if you see “Windows protected your PC”, choose More info › Run anyway.

The installers are built by GitHub Actions from the source on GitHub. If you prefer, you can build it from source yourself.
