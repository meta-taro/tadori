# 002 — `tadori check` の最小版

## 目的

台帳のつながりの穴を一覧で出す（PRD §4）。

## やること

- Node の CLI（pnpm）。引数は台帳のあるディレクトリ
- 出す穴は 5 種
  1. ケースの無い仕様の文
  2. 証跡の無いケース
  3. 証跡がシートの変更より古い（run.json の `sheet.sha256` と現在のシートの比較）
  4. 再発防止の無い指摘
  5. 存在しない ID を指している
- 穴があれば exit 1、無ければ exit 0（CI と pre-commit で同じものが出る）
- 出力は 1 行 1 件、`種別<TAB>ID<TAB>説明`

## 完了条件

- [ ] 001 の見本に対して、README に列挙した穴が過不足なく出るテストがある
- [ ] 穴を直した見本で exit 0 になるテストがある
- [ ] 1〜5 の種別ごとにテストがある
