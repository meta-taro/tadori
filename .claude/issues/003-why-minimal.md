# 003 — `tadori why <ID>` の最小版

## 目的

1 件から上下に辿った全部を出す（PRD §2 の 5 点が並ぶ状態）。

## やること

- 引数は SPEC / TC / RUN / F / R のどの ID でもよい
- 上（仕様の文の側）と下（再発防止の側）へ辿り、出会ったものを全部出す
- 根拠（設計書の章・ソースの file:line・試験書の No.）はそのまま出す。tadori が中身を開きに行かない
- 存在しない ID は exit 1 で「無い」と出す（空の出力で終わらない）
